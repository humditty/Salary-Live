# 🕒 今日实时赚薪计算器
## 摸鱼治愈神器 · 每秒都在赚钱 · 全屏沉浸式展示

### ✨ 项目简介
专为打工人打造的**实时工资计算器**，输入月薪和上下班时间，即可按秒计算今日已赚金额。
就算在摸鱼，也能清晰看到每一秒都在进账，缓解上班焦虑，打工瞬间更有动力～

---

### 🚀 核心功能
- 💰 **实时薪资计算**
  按法定 **21.75 天** 计薪，金额精确到**小数点后 4 位**，数字跳动丝滑解压

- ⏰ **灵活时间设置**
  自定义月薪、上下班时间，自动计算日薪 / 时薪，配置自动本地保存

- 😴 **午休模式一键开关**
  勾选「**不午休！**」自动隐藏午休设置，全程连续计薪
  不勾选则正常扣除午休时间，更贴合真实上班场景

- 🖥️ **全屏沉浸式展示**
  点击金额一键进入全屏超大数字模式
  全屏金额**强制不换行**，观感干净整洁

- 🧾 **货币符号可隐藏**
  自由开关「¥」符号，只看纯数字更极简、更低调

- 🌙 **深色护眼界面**
  低饱和度深色模式，上班挂着不显眼、不刺眼

---

### 📝 使用方法
1. 复制全部代码，新建文本文件并粘贴
2. 文件重命名为 `salary.html`（后缀必须为 `.html`）
3. 双击用浏览器打开即可使用
4. 输入月薪 → 设置上下班时间 → 自动开始计时
5. 点击金额进入全屏，点击任意位置 / 按 `ESC` 退出

### 🔧 自定义配置
所有配置项均保存在浏览器 `localStorage` 中：
- `monthlySalary` - 月薪金额
- `workStart` / `workEnd` - 上下班时间
- `noRestMode` - 不午休模式（true/false）
- `restStart` / `restEnd` - 午休起止时间
- `showUnit` - 是否显示¥符号（true/false）

如需重置，打开浏览器开发者工具 → Application → Local Storage → 删除相关键值。

---

### 📊 计算逻辑
1. **日薪 = 月薪 ÷ 21.75**（法定月计薪天数）
2. **时薪 = 日薪 ÷ 每日工作小时数**
3. **今日已赚 = 时薪 × 已工作小时数（扣除午休）**

午休规则：
- 开启「不午休」模式：总工时 = 下班 - 上班
- 正常模式：总工时 = (下班 - 上班) - 午休时长
