# 今日赚薪实时计算器

一个实时计算你在工作日已赚金额的网页工具，精确到小数点后4位，让每一秒的劳动都可视化！

## 功能特点

- ⏰ **实时计算** - 基于当前时间精确计算已工作时长
- 💰 **精确到毫秒** - 金额显示精确到0.0001元
- 🏖️ **午休智能处理** - 支持午休时间自动扣除或全天连续计算
- 📱 **全屏展示** - 点击金额可全屏显示，方便查看
- 💾 **自动保存** - 所有设置自动保存到本地存储
- 🌙 **深色主题** - 护眼的深色界面设计

## 使用方法

### 1. 基础设置

- 在浏览器中打开 `index.html`
- 输入你的税前月薪
- 设置上下班时间（默认 09:00 - 18:00）

### 2. 午休配置

- 默认情况下，午休时间（12:00-13:00）会从总工作时长中扣除
- 开启「不午休」模式，全天工作时间连续计算
- 午休时段会显示"带薪休息"的提示

### 3. 金额显示

- 默认显示"¥"符号
- 可通过开关隐藏金额单位
- 点击金额数字可全屏显示（点击或按ESC退出）

## 计算逻辑

### 核心算法

1. **日薪 = 月薪 ÷ 21.75天**（法定月计薪天数）
2. **时薪 = 日薪 ÷ 每日工作小时数**
3. **今日已赚 = 时薪 × 已工作小时数**

### 工作时长计算

- **包含午休扣除**：工作时长 = (下班时间 - 上班时间) - 午休时长
- **不午休模式**：工作时长 = 下班时间 - 上班时间
- 已工作时长根据当前时间动态计算，扣除午休时段

### 状态提示

- **上班前**：显示"还没到上班时间"
- **上班中**：显示"上班中！就算摸鱼也在赚钱"
- **午休时**：显示"午休时间！带薪休息"
- **下班后**：显示"今日打工结束"

## 开发说明

### 本地运行

直接使用浏览器打开 `index.html` 即可，无需任何服务器。

### 刷新频率

程序每100毫秒自动刷新一次，确保金额跳动流畅。

### 数据存储

所有配置保存在浏览器 LocalStorage 中：
- `monthlySalary` - 月薪
- `workStart` / `workEnd` - 上下班时间
- `noRestMode` - 不午休模式
- `restStart` / `restEnd` - 午休时间
- `showUnit` - 单位显示开关

## 常见问题

**Q: 为什么我的日薪/时薪显示为0？**
A: 请确保已输入有效的月薪数值（大于0）。

**Q: 全屏显示如何退出？**
A: 点击屏幕任意位置或按ESC键即可退出全屏。

**Q: 为什么午休期间也显示在计算？**
A: 午休期間状态显示为"带薪休息"，金额会保持静止，不会继续累积。

**Q: 数据会丢失吗？**
A: 设置保存在浏览器本地存储中，除非清除浏览器数据，否则会一直保留。
